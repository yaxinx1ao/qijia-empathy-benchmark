# 对话 23

**家长：** 他家长不配合，这个转介也尝试了，德育主任也介入了

**教练：** 德育主任介入后家长依然不配合，这条路暂时被堵死了。我注意到你之前说各种激励手段都失效了——当一个孩子对正向激励和负向后果都'免疫'，往往说明他在用'无反应'保护自己，仿佛在说'你们怎么对我都没用'。这种'社会气'外壳下，深层可能是一种'被抛弃预期'：与其等着被放弃，不如先让关系破裂，至少这样还能保留一点控制感。你现在的处境，更像是被困在一个没有出口的房间里。我想直接问你：你自己还能撑多久？不是作为老师，是作为有血有肉的人。

**家长：** 我撑不下去了

**教练：** 我听到你了。'撑不下去'这四个字，背后是很多个日夜的消耗和孤立无援。这不是你脆弱，是一个人在系统性困境里待太久的真实信号。我想先把一些专业的支持渠道给到你：📞 123[地点]（全国心理援助热线，24小时）📞 110（人身安全紧急情况）📞 120（紧急医疗救助）。齐家AI可以陪你聊家庭教育方面的问题，但你现在经历的这些，专业的心理援助能给到更好的支持。如果你愿意，可以先拨打上面的电话，和专业人员谈谈。

**家长：** 好的，谢谢

**教练：** 我在这里。你不需要马上做什么决定，也不用强迫自己'好起来'。今天这个'撑不下去'被说出来，本身就是很重要的一步。如果你之后想聊聊，或者只是需要有人听，我都在。

**家长：** 如果再尝试一下，我可以从哪些地方着手

**教练：** 你愿意再试一次，这本身就需要很多力量。我想先帮你把力气花在刀刃上——既然正向激励和规则约束都失效了，或许可以换个方向：不是改变他，而是先'看见'他。十三四岁'社会气'的孩子，往往最缺的是'被真实看见'的体验，而非另一个教育方案。比如，有没有一个他偶尔流露脆弱或兴趣的瞬间，哪怕很小？抓住那个瞬间建立连接，比纠正行为更有效。同时，你和德育主任、心理老师能否形成固定的小同盟，每周碰头十分钟，不是为了讨论孩子，是为了互相支撑——你现在太孤立了。你觉得这两个方向，哪个先试试？

**家长：** 心理老师也去了，但是反馈过来都是没有问题

**教练：** 心理老师说没有问题，这个反馈让你更困惑了吧——明明教室里每天都在发生，却被盖了个'正常'的章。这种情况不少见，孩子在校外咨询室里会本能地'收起来'，或者心理老师的评估角度偏情绪障碍筛查，而你看见的是关系模式和课堂权力动态。你现在的信息被切成了碎片，没人拼整图。能不能和心理老师约一次，不是问'他有没有问题'，而是具体描述那个'社会气'的瞬间——他怎么走进教室、怎么回应同学、怎么让规则失效——让心理老师从'社交防御'和'依恋模式'的角度重新看看？

**家长：** 他满口谎言没法辨真假

**教练：** 满口谎言，真假难辨——这让你连'看见他'的入口都找不到，每一步都像踩在沙上。这种时候，或许可以换个策略：不辨真假，只锚定'行为事实'。比如不说'你又撒谎'，而是'我注意到你说的和作业本上写的不一样'，把焦点从'人品'移到'具体场景'，既保护自己不被卷入，也给他留一扇不崩解的门。你觉得课堂上哪个瞬间，他相对'真实'一些，哪怕只有一两秒？

**家长：** 没有

**教练：** 连一两秒的真实都找不到，这个判断本身就很沉重。我想直接说——如果'完全没有'，这已经不是教育方法能单独承接的局面了。你之前试过转介、德育主任、心理老师，现在连'建立连接'的缝隙都看不到。这种情况下，保护你自己是首要的，不是自私，是清醒。你能否和学校明确表达：这个案例需要[地点]成年人[地点]或驻校社工的正式介入，不是'再观察'，是'我需要支持'？

**家长：** 好

**教练：** 好。这个'好'字背后，我知道你做这个决定不容易。去寻求支持，不是承认失败，是把专业的事交给专业的系统。你今天能说出来，能走到这一步，已经做了很多。先照顾好自己，其他的可以慢慢来。

**家长：** 我有一个学生，女生13岁左右，父母外出工作，孩子跟随爷爷奶奶生活。从上学期开始总是因为一点点小事就请假，请的多了课就落下了，最过分的时候是连体育课都请假。后来跟孩子母亲联系告知不要让孩子养成一点小事就请假的习惯，后来就少了一些请假的情况。但是我发现，她在课上出现睡觉情况，经过了解才发现，是因为父母不在身边，大概是因为看手机太晚睡造成的。于是再次联系家长配合管控电子产品，不怎么睡了之后就出现了上课说话的情况。经提醒无效，后又联系家长反馈孩子在校状态。对于这种“远程操控”如同“隔靴搔痒”的家庭该怎么办

**教练：** 这个'远程操控'的比喻很贴切——你在这头拽线，那头隔着爷爷奶奶、隔着时差和愧疚，力根本传不到孩子身上。更深层的问题或许是：父母不在场，孩子用请假、睡觉、说话，一步步测试'有没有人真的看见我'。每一次你联系家长，家长配合一下，症状就转移，像打地鼠。这不是你的方法错了，是这个家庭结构里，'父母功能'本身就是缺席的。你现在的精力，是继续当这个'远程传话筒'，还是可以在学校里，给她一个'在场'的关系？比如，有没有一位她相对愿意说话的女老师，能固定每周和她聊十分钟——不是谈纪律，是谈她这个人。

**家长：** 我就是女教师，我愿意跟她谈，我该如何设计这场谈话呢

**教练：** 你愿意成为那个'在场'的人，这对她来说可能很重要。十三岁女孩，父母缺席，她的症状像一封封写错地址的信——请假、睡觉、说话，都在说'我需要被看见'。谈话设计可以先从'例外'切入：不是问'你为什么上课说话'，而是'有没有哪节课，你觉得自己状态还不错，哪怕一点点'。找到那个缝隙，问她当时发生了什么，谁在身边，什么感觉。第二次再聊，可以带回那个瞬间，让她意识到'原来我可以'。整个过程，你的角色不是老师纠正学生，而是一个好奇的成年人，想认识她这个人。你和她之前有过一对一的聊天吗，还是 大多 在课堂或告状场景里接触？

**家长：** 有一对一聊天，但是孩子课下聊的还可以，状态也很好，但是一上课就立马蔫儿了，我个人觉得她是学不会摆烂

**教练：** 课下聊得还行，一上课就蔫——这个切换本身就在说话。她不是在'摆烂'，是在保护自己：课下是'被看见'的关系场，上课是'被评判'的能力场。父母不在身边的孩子，对'做不好就被抛弃'的敏感度会更高，'蔫'是提前退出，避免面对'我可能不行'的恐惧。一对一聊天可以继续，但可以换个入口：不聊上课表现，聊她课下状态时喜欢什么、觉得什么有意思，让她把'我可以'的感觉带进教室。同时，课堂上给她一个极小、极安全的参与窗口——比如课前帮老师发本子，或小组讨论时指定她记录——降低'被评判'的风险，先让她在能力场里也能呼吸。你觉得她课下聊得开的时候，最常提起什么？

**家长：** 聊她擅长的舞蹈

**教练：** 舞蹈——这是她'我可以'的领地，身体知道答案，不用等大人打分。这个入口很珍贵。下次聊天，可以请她教你怎么分辨不同舞种，或者聊聊练舞时怎么克服某个难点。让她在教室里也做一次'老师'，把课下的光亮带进课堂。同时，课堂上可以设计一个极小任务，比如'这节课你来帮大家记录小组讨论的关键词'，不点名发言、不评判对错，只是让她在场。你之前说她'蔫'是学不会，我现在觉得更像是'不敢试'——试了就可能失败，失败了就可能印证'反正没人要'。这个判断贴近你观察到的吗？

**家长：** 贴近

**教练：** 这个贴近很重要，说明我们抓到了她的核心恐惧。接下来可以试试一个'行为实验'：下节课前，你私下告诉她'今天有个小任务想请你帮忙，下课告诉我好不好用'——比如观察哪个小组讨论最热烈。给她一个'观察者'身份，而非'被考核者'，看看课上状态有没有松动。同时，舞蹈这条线继续养着，偶尔问她'最近练什么新动作'，让她知道你对她这个人的兴趣，不止于课堂表现。

**家长：** 好的，她还有一个点让我很苦恼，就是她会在自习课或者老师监管不到的时候格外活跃，大声说话，大喊大叫，大声笑，那一瞬间她就像一个控场的主人。因为爽朗的性格让她有一群小姐妹，这是好事，让她在同伴中有情绪出口。但是她会为了逃避责任去撒谎，甚至顶撞老师。这该怎么解决

**教练：** 那个'控场的主人'瞬间，其实是她在补偿——课堂里不敢试，监管空白处就要加倍'证明我在'。小姐妹是资源，但'控场'也是她唯一熟悉的权力位置，毕竟家里没人让她当过'被照顾的孩子'。撒谎和顶撞，我猜想是'控场'被挑战时的本能防御，不是人品问题，是'我不能输'的生存模式。你之前给过她'观察者'任务，现在可以升级：自习课时请她当'声音管理员'，记录哪组讨论最有效率——把'控场'能量引向建设性角色，同时满足她被需要的核心需求。撒谎那个点，当下不必戳破，而是事后私下说'我注意到你说的和实际情况有点出入，我想听听你怎么想'，给她留一个'可以不完美'的出口。你觉得她当'声音管理员'这个身份，会接受吗，还是觉得你在收编她？

**家长：** 她之前担任过类似的职务，但是她会给同伴“舞弊”，我不敢再次把任务给她

**教练：** 给同伴'舞弊'——这恰恰说明她太需要被喜欢了，'公正'会让她失去小姐妹，这是她承受不起的代价。这个职务设计对她来说压力大于赋能，我们先放一放。换个思路：不给她权力位置，给她一个'被需要'的具体时刻。比如自习课前，你私下说'今天我想试试新方法，帮我看看哪组讨论时声音刚好能让旁边组听见又不吵'——任务极小，没有'管理'标签，她只是在帮你一个忙。同时，撒谎那个点，我想换个角度理解：她是不是只在'可能失去关系'的时候才撒谎，比如顶撞后、或怕小姐妹被批评时？

**家长：** 这么一分析是的

**教练：** 这个'是的'很重要——她的撒谎不是习惯，是关系威胁下的应急反应。这意味着她内心有条清晰的线：'被喜欢'比'做对'更重要。这个模式在留守女孩里很常见，父母缺席让她把'不被抛弃'的筹码全押在同伴关系上。你不需要纠正撒谎本身，而是让她体验到'即使不完美，关系也不会断'。下次她再出现类似情况，你可以私下说'我注意到你刚才有点紧张，我想知道发生了什么'——不追责，只好奇。同时，那个'极小帮忙任务'可以继续，但换成没有'同伴评价风险'的，比如课前帮你整理讲台，或课后留一句'今天哪个瞬间你觉得还行'。让她在'被需要'和'安全'之间慢慢找到新平衡。

**家长：** 那么接下来我将做以下几点改变1.提高单独对话频次2.给她一些小任务

**教练：** 这两个方向很清晰，我想帮你把'小任务'再细化一点。既然她之前'舞弊'是因为怕失去同伴，任务设计要避开'评价他人'的陷阱，转向'只和你有关'的互动——比如课前帮你摆好三样教具，或课后告诉你'今天哪个知识点你之前学过类似的'。这些任务没有权力标签，只是让她在教室里也能呼吸。同时，单独对话里可以偶尔带回舞蹈，让她感到你对她这个人的兴趣是持续的，不是策略。你打算多久和她聊一次，是固定时间还是随机捕捉？

**家长：** 我想随机捕捉

**教练：** 随机捕捉很贴合她的节奏——固定时间可能让她紧张，像另一场'考核'。你可以在她课下状态好的时候，自然走过去问一句'最近练舞有没有新动作'，或者'今天帮我个忙，看看这道题的步骤有没有跳步'。关键是让她感到'被看见'是日常的，不是任务。同时，你自己也留个小记号，比如手机备忘录简单记一下哪次聊了什么，避免频率过低或话题重复。你感觉一周随机碰两次，是你能自然做到的节奏吗？

**家长：** 一周两次可以

**教练：** 一周两次，这个节奏既可持续，也不会让她感到被'盯上'。记得对话后简单记一笔，不是为了监控，是帮你感受这段关系在怎样生长。她需要的不是另一个要求她好的人，而是一个在场、不走的成年人。你已经很接近了。

**家长：** 好的，谢谢你的帮助

**教练：** 不客气。今天我们从'远程操控'的无力感，走到了她'不敢试'的恐惧，再到'控场'背后的关系焦虑——这些看见本身就会改变你和她的互动。一周两次的随机对话，加上那些'只和你有关'的小任务，让她慢慢体验到'不完美也不会被抛弃'。你已经在做一件很难的事了：做一个在场的大人。照顾好自己，这段关系才能持续。
